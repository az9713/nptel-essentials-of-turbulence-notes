Numerical laboratory

Reproduce the programs already developed in the chapters: dimensional scaling, conservation identities, random processes, spectra, simulation cost, and filtering.

This laboratory is a directory and command-line launcher for the existing chapter programs. Read each chapter for its assumptions, model definitions, units, and worked interpretation.

Download the Python launcher with the rest of the repository. Python and NumPy are required to run the examples. From the repository root:

python numerical_lab.py --list
python numerical_lab.py --chapter 5
python tools/check_chapter_code.py

The launcher runs all Python listings in the selected chapter in isolated processes. The verification tool compares their output with the printed output in the book; the execution record reports actual results and platform differences.
